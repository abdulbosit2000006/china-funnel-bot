# Админка бота — как пользоваться

Админ-панель видите только вы (Telegram ID из `ADMIN_TG_IDS`). Открыть: `/start` или `/admin`.

## Загрузить PDF (lead magnet)

1. Отправьте боту PDF-файл (до 20 МБ) **с подписью**:
   ```
   canton-fair-2027 | Canton Fair 2027: safar hisob-kitobi
   ```
   Слева от черты стоит `slug`: короткое имя латиницей, цифры и дефис. Справа — название, которое увидит клиент.
2. Бот сохранит файл в облако (Cloudflare R2) и покажет карточку версии:
   - выберите тип: Выставка / Производство / Оборудование / Сырьё;
   - нажмите **✅ Сделать активной версией**.
3. Новый PDF с тем же `slug` становится **новой версией** (v2, v3…). Старая не удаляется, а после активации новой помечается как устаревшая.

## Ссылка для поста в канале

В карточке активной версии нажмите **🔗 Создать ссылку для поста**. Появится ссылка вида
`https://t.me/abdulbosit_xitoy_assistant_bot?start=canton_fair_2027_c1`.

Её ставят на кнопку под постом. Для каждого поста лучше делать отдельную ссылку: тогда видно, какой пост приводит людей. Счётчик «входов» стоит рядом с каждой ссылкой.

## Что видит клиент

1. Нажимает кнопку под постом → бот пишет приветствие и сразу присылает PDF, без анкет.
2. Следом приходит предложение помощи с кнопкой **🤝 Muhokama qilmoqchiman**.
3. Если клиент нажал кнопку, вам приходит карточка **🔥 Клиент хочет обсудить**: кто, какой материал, с какой ссылки, какие PDF он уже брал, кнопка «Открыть чат».

Проверить самому: откройте свою ссылку `?start=...`. С кодом кампании бот показывает вам ровно то, что видит клиент.

## Разделы панели

- **📊 Dashboard**: пользователи, входы, выданные PDF, нажатия «обсудить» за 24 ч, стадии лидов.
- **📄 Lead Magnets**: все материалы (🟢 активен, 📝 черновик, ⚪️ устарел, ↓ сколько раз выдан).
- Остальные разделы появятся в следующих фазах: follow-up и квалификация, публикация в канал, статистика, автоматический research.
